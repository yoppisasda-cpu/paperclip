# Social Media Agent Team for Paperclip

Tim agen otonom untuk produksi, QC, dan publikasi konten video pendek (TikTok, Instagram Reels, YouTube Shorts).

## Roster Tim

1. **Social Lead (`social_lead_instructions.md`)**
   - Mengarahkan riset tren & ide konten harian/mingguan.
   - Mengoordinasikan pembagian tugas ke Copywriter dan Video Specialist.
   - Mengambil keputusan approval final sebelum diteruskan ke Publisher.

2. **Viral Copywriter (`copywriter_instructions.md`)**
   - Menulis hook 3 detik pertama, naskah narasi, caption SEO, dan rekomendasi audio/lagu tren.
   - Menyiapkan format subtitle/closed captions.

3. **Hyperframes Video Specialist (`video_specialist_instructions.md`)**
   - Merancang template video vertikal (9:16) menggunakan HyperFrames HTML/CSS/JS.
   - Mengintegrasikan voiceover TTS lokal via VoiceStudio API (`http://localhost:3900`).
   - Melakukan rendering video MP4 berkualitas tinggi.

4. **QC Specialist (`qc_instructions.md`)**
   - Memeriksa kesesuaian durasi (15-60 detik), rasio aspek (9:16), ritme pacing, sinkronisasi audio-visual.
   - Melakukan cek kepatuhan hak cipta musik dan konten aman (brand safety).

5. **Multi-Platform Publisher (`publisher_instructions.md`)**
   - Menjadwalkan dan mengunggah video ke TikTok, Instagram Reels, dan YouTube Shorts.
   - Memonitor metrik engagement 24 jam pertama.
